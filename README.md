## How I work

1. Name the user, the painful problem, and why it matters now.
2. Define the smallest test that can disprove the idea.
3. Ship a clickable artifact in hours and a usable v1 in days.
4. Instrument the critical behavior, watch real usage, and iterate.
5. Document decisions and hand over a clear production path.
